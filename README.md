# 📋 Kanban Task Board

A simple and interactive Kanban task management board built using HTML, CSS, and JavaScript. Organize your tasks, track your progress, and move tasks between different stages using drag-and-drop functionality.

## ✨ Features

- **➕ Add Tasks:** Create tasks with a title and description.
- **🖱️ Drag and Drop:** Move tasks between To-do, In Progress, and Done columns.
- **🗑️ Delete Tasks:** Remove tasks you no longer need.
- **💾 Persistent Storage:** Tasks are saved in the browser's Local Storage and remain available after refreshing the page.
- **📊 Task Counters:** Automatically track the number of tasks in each column.
- **🪟 Modal Interface:** Use a modal window to add new tasks.
- **🔄 Automatic Updates:** Task counts and saved data update when tasks are added, moved, or deleted.

## 🛠️ Technologies Used

- **HTML5** — Structure of the application.
- **CSS3** — Styling and layout.
- **JavaScript** — Task management, drag-and-drop functionality, and DOM manipulation.
- **Local Storage API** — Persisting tasks across page reloads.

## 📖 How to Use

1. Open the application in your browser.
2. Click the button to open the task creation modal.
3. Enter a task title and description.
4. Click **Add Task** to create a task in the To-do column.
5. Drag tasks between the To-do, In Progress, and Done columns as you work.
6. Delete tasks when they are no longer needed.
7. Refresh the page to see your tasks restored automatically.
